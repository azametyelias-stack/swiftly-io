```
SUPPORT (IT Department):
├─ Répond aux questions
├─ Corrige les problèmes techniques
├─ "Mon transaction ne marche pas"
└─ Réactif (répond après le problème)

CUSTOMER SUCCESS:
├─ Assure que l'utilisateur réussit
├─ Aide l'utilisateur à atteindre ses objectifs
├─ "Comment je peux économiser 1M de FCFA?"
└─ Proactif (aide avant le problème)

TRAVAIL ENSEMBLE:
├─ Support: "Problème technique résolu"
├─ CS: "Maintenant, tu veux atteindre quel objectif?"
└─ Résultat: Utilisateur heureux!
```
